# Mood — Agencia Creativa

Landing page estática con HTML, CSS y JavaScript en un solo archivo.

## Uso
1. Descomprime el ZIP.
2. Abre `index.html` en Visual Studio Code.
3. Abre en el navegador o usa Live Server.

## Personalización
- Cambia los enlaces e imágenes por el material final de Mood.
- Las fotos actuales vienen de Unsplash y requieren conexión a internet.
- No se incluyó la lista de roles/personas, tal como se solicitó.
- La página es una presentación visual; no tiene formulario ni backend.
